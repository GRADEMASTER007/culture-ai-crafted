
This is a very large scope. I'll build it in phases so we get a premium, working site quickly, then layer in payments, email, and AI. Here's what I propose for Phase 1 (this turn), and what I'll defer.

## Phase 1 — Ship a premium, production-shaped site (this turn)

**Design system**
- Bold, editorial premium wellness aesthetic (deep botanical green + warm cream + amber accents), custom serif display + clean sans body, oklch tokens in `src/styles.css`, glass cards, subtle motion.
- Not purple, not generic SaaS. Distinctive African-wellness feel.

**Pages (TanStack Start routes)**
- `/` Home — hero (image-based, video-ready slot), featured products, why-choose grid, fermentation education, testimonials, blog preview, newsletter.
- `/shop` — category filters, product grid.
- `/shop/$slug` — product detail with gallery, long description, FAQ, related products, schema.org Product JSON-LD.
- `/blog` + `/blog/$slug` — article list + article page with FAQ + Article JSON-LD.
- `/about`, `/contact`.
- 404 already handled.

**Product / content data (AI-managed, no admin panel)**
- `src/content/products.ts` — typed JSON array (SKU, name, slug, price ZAR, sale, stock, category, short/long desc, gallery, alt, SEO title/desc/keywords, FAQ, shipping, related).
- `src/content/posts.ts` — blog articles same shape.
- Editing = edit the file; the site rebuilds. Matches the "no admin, git/AI-managed" requirement.
- Seeded with the products listed (Water Kefir, Milk Kefir, Kombucha SCOBY, Ginger Bug, ACV Mother, Sourdough, Culture Package, sugar mixes) and 3 starter blog posts.

**Cart & checkout scaffolding**
- Client-side cart (Zustand) with add/remove, ZAR formatting.
- `/cart` and `/checkout` pages with form + order summary.
- Checkout "Place order" is a stub button that shows a "payments coming soon — Yoco / PayFast / PayPal" state. Real gateway integration is Phase 2 (needs your merchant accounts + secrets).

**SEO / AI-search**
- Per-route `head()` with title, description, canonical, og:*, twitter:*.
- Organization + WebSite JSON-LD in `__root`.
- Product JSON-LD on product pages, Article + FAQPage on blog, BreadcrumbList on deep routes.
- `src/routes/sitemap[.]xml.ts` generated from products + posts.
- `public/robots.txt` allowing all + sitemap reference.
- Geo meta (ZA), currency ZAR.
- Analytics placeholders (GA4 / GTM / Search Console) wired via env-driven `<script>` slots, off by default.

**AI chatbot (floating widget)**
- Persistent floating "Living Culture AI Assistant" on every page.
- Backed by a TanStack server route `/api/chat` using Lovable AI Gateway (`openai/gpt-5.6-sol`), system prompt scoped to only recommend products from `products.ts` (passed into the prompt).
- Streaming, markdown rendering, message history in memory (per session, no DB).

**Images**
- Generate a small set of premium hero + category images with imagegen (cinematic fermentation, kefir grains macro, kombucha jars, warm African kitchen). Product cards use these as placeholders you can swap by editing `src/content/products.ts`.
- No video generated by default; hero has a `<video>` slot with poster fallback so you can drop in an MP4 later.

**Perf / a11y**
- Lazy images, semantic HTML, single H1 per page, alt text, responsive from 320px up.
